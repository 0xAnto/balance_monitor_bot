# Aptos Balance Monitor Bot 🤖

A Telegram bot that monitors Aptos wallet addresses and sends alerts when the balance drops below a specified threshold.

## Features

-   **Multi-Wallet Monitoring**: Track multiple Aptos addresses simultaneously.
-   **Custom Thresholds**: Set individual alert thresholds for each wallet (default: 10 APT).
-   **Hourly Checks**: Automatically checks balances every hour.
-   **Stateless Architecture**: Uses **Supabase** (PostgreSQL) for storage, allowing deployment on any platform (Render, Railway, Vercel, Replit, etc.).

## Prerequisites

-   Node.js (v18 or higher)
-   A Telegram Bot Token (from [@BotFather](https://t.me/BotFather))
-   A Supabase Project (Free tier is sufficient)

## Setup

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/0xAnto/balance_monitor_bot.git
    cd balance-monitor-bot
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Configure Environment**:
    Create a `.env` file in the root directory:
    ```env
    BOT_TOKEN=your_telegram_bot_token
    SUPABASE_URL=your_supabase_project_url
    SUPABASE_KEY=your_supabase_anon_key
    APTOS_NETWORK=mainnet
    ```

4.  **Setup Database**:
    -   Go to your Supabase project's **SQL Editor**.
    -   Run the following SQL command to create the table:
        ```sql
        create table monitors (
          id bigint generated by default as identity primary key,
          chat_id text not null,
          address text not null,
          threshold float default 10,
          name text,
          created_at timestamp with time zone default timezone('utc'::text, now()) not null,
          unique(chat_id, address)
        );
        ```

## Running Locally

Start the bot in development mode:
```bash
npm run dev
```

## Bot Commands

-   `/start` - Initialize the bot and see the welcome message.
-   `/monitor <address> [threshold]` - Start monitoring an address.
    -   Example: `/monitor 0x123... 50` (Alerts if balance < 50 APT)
-   `/list` - List all addresses you are currently monitoring.
-   `/delete <address>` - Stop monitoring a specific address.

## Deployment

Since the bot uses Supabase, it is stateless and can be deployed easily.

### Option 1: Render / Railway / Vercel
1.  Connect your GitHub repository.
2.  Set the **Build Command** to `npm install && npm run build`.
3.  Set the **Start Command** to `npm start`.
4.  Add your Environment Variables (`BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_KEY`).

### Option 2: VPS with PM2
1.  Upload code to your server.
2.  Install dependencies and build: `npm install && npm run build`.
3.  Start with PM2: `npx pm2 start ecosystem.config.js`.
